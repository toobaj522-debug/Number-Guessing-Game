# Number-Guessing-Game
A simple console-based number guessing game developed using C++.

## How It Works

The program asks the player to enter a number repeatedly until they guess the correct number.

The correct number is 58.

## Features

- Repeatedly accepts user guesses
- Uses a do-while loop
- Checks whether the guess is correct
- Displays a congratulatory message when the correct number is guessed

## Concepts Used

- C++
- User Input and Output
- Variables
- do-while Loop
- Conditional Logic
- Comparison Operators

## Example

Enter number for guess:
25

Enter number for guess:
40

Enter number for guess:
58

Congratulations. You won.
